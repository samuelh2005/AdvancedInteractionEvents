# v1.0.0

Initial release of Advanced Interaction Events.

## Features

- Added the `EventHandlerType` registry for registering custom event handler types.
- Added codec-based `EventData` serialisation with a `type` discriminator, allowing event payloads to be encoded and decoded through Minecraft's data-serialisation system.
- Added server-side handling for custom click-action packets. Registered event handlers can implement `ClickActionHandler` to receive decoded click events for a player.
- Added the built-in `advanced_interaction_events:secret_command` event handler, which executes a configured command as the player who triggered the event.
- Added error logging and player-facing command syntax errors for invalid or malformed custom click-action payloads and commands.
- Added `EventDataEncoders` for serialising events to NBT or chat ClickEvents or Dialog StaticActions.

## Compatibility

- Minecraft `26.2`
- Fabric Loader `0.19.5` or newer
- Java `25` or newer
